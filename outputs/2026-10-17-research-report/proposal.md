## A. Design.md §9 차트에 더할 규칙

### 그림 머리와 출처
- 문서·리포트의 그림은 `그림 N` + **결론 문장 제목** → 측정 대상·단위·기준 부제(`--fs-sm` text-2) → 차트 → 출처 줄(`--fs-xs` text-3, 위에 1px `--border`). 명사형 제목(`우라늄 가격 추이`) 금지. §13 슬라이드 규칙을 문서로 넓힌다.
- 화면 UI 패널 차트(대시보드)는 지금처럼 명사형 제목을 허용한다. 결론형은 읽는 문서에만.

## B. Design.md 새 절 — §15 리포트(문서형), 지금 §15 변경 이력은 §16으로

| 항목 | 규격 |
|---|---|
| 캔버스 | 화면 최대 폭 880px, 인쇄 A4(`@page` 14mm·16mm). 쪽마다 `break-before: page`, 그림·표는 `break-inside: avoid` |
| 쪽 | 위 2px `--text` 선 → 러닝 헤더(왼쪽 `발행물 · 호`, 오른쪽 섹션명, `--fs-xs` text-3) … 러닝 푸터(왼쪽 발행일·기준일, 오른쪽 `2 / 4`) |
| 본문 단 | 본문은 기본 타입(16/1.65, 68ch). 1024px 이상에서 왼쪽 22%를 비워 들이고, 그림·표는 전폭 |
| 1쪽 | 결론형 제목(h1) + 요약 문단 1개 + Stat 3개 + 인용 1개 + 목차(섹션·그림·표 쪽 번호) |
| 표 | 위 2px `--text` 선 + 결론형 표 제목(`표 N`). Panel 소구분 행(`--surface-2`, `--fs-xs` 600). 보조값(전월 대비·t값)은 값 아래 괄호 `--fs-xs` text-3. 표 아래 주석 |
| 값 없음 | `–` = 계산할 수 없음/데이터 없음(§10), **`비공개` = 값은 있으나 공개 안 함**(새로 구분) |
| 각주 | 본문·그림 부제에 `*` `**` `***`, 쪽 아래에 모아 적고 마지막 줄 `모든 그림 출처: …` |

## 뒤집고 싶을 만한 판단
1. 리포트 본문을 평서문(~다)으로 썼다. §11 해요체를 따르려면 전부 바꿔야 한다.
2. 표 머리에 진한 채움(MAS·GS)을 쓰지 않고 2px 윗선으로 대신했다. 하네스 Table 규격(배경 없음)을 지키려는 선택.
3. 워터폴 증감을 발산 색(버건디/파랑)으로 칠했다. 색을 빼고 회색 + 부호만 쓰는 안도 있다.
4. 본문 단 들여쓰기(왼쪽 22% 비움)는 GS 형식을 따른 것이다. 왼쪽 여백이 비어 보이면 전폭으로 되돌릴 수 있다.
