# glossary — 화면 용어집

한 개념은 한 단어로 쓴다(Design.md §11). 새 화면을 만들 때 여기와 대조하고, 새 용어는 먼저 여기에 추가한다.
"쓰지 않는 말"은 틀린 말이 아니라 **이 하네스에서 통일하지 않은 말**이다. 프로젝트가 다른 용어를 이미 쓰고 있으면 그 프로젝트 용어집을 따르고 여기에 메모한다.

## 공통 UI
| 쓰는 말 | 쓰지 않는 말 | 메모 |
|---|---|---|
| 닫기 | 취소(대화상자 닫을 때) | `취소`는 진행 중 작업을 실제로 취소할 때만 |
| 다시 시도 | 재시도, 새로고침(실패 후) | |
| 불러오지 못했어요 | 조회 실패, 로딩 오류 | |
| 저장했어요 | 저장되었습니다, 저장 완료 | |
| 기준 | 기준일시, as of | `2026.10.14 15:30 기준` |
| 필터 초기화 | 리셋, 전체 해제 | |
| 더 보기 | 더보기, 펼치기(목록) | 띄어 쓴다 |
| 전체 | 모두, All | 기간 세그먼트의 마지막 칸 |

## 투자·포트폴리오
| 쓰는 말 | 쓰지 않는 말 | 메모 |
|---|---|---|
| 평가금액 | 평가액, 잔고 | |
| 매입금액 | 투자원금, 원금 | |
| 평가손익 | 수익금, 손익금 | 부호와 시장 방향 색(§2) |
| 수익률 | 수익율, 이익률 | |
| 종목 | 주식, 티커(화면 문구에서) | 코드는 `005930`처럼 6자리 그대로 |
| 비중 | 비율, 구성비 | 소수 1자리 % |
| 등락률 | 변동률, 증감률(시세) | 소수 2자리 %, 한국식 색 |
| 최대 낙폭(MDD) | 드로다운 | 처음 한 번 풀어 쓴다 |

## 상권·매장
| 쓰는 말 | 쓰지 않는 말 | 메모 |
|---|---|---|
| 매출 | 매상, 판매액 | |
| 점포 수 | 업소 수, 매장 수 | |
| 증감률 | 성장률(전년 대비일 때) | 비교 기준을 붙인다: `전년 같은 분기 대비` |
| 상권 | 지역, 구역 | 행정동과 섞지 않는다 |
