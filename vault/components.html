모달 · 확인 대화상자

  • 네이티브 <dialog> + showModal(). 폭 --modal-w(480), surface + border + --r-lg + --shadow-pop, 배경 --backdrop
  • Tab/Shift+Tab은 대화상자 안에서 순환, Esc·배경 클릭으로 닫힘, 닫히면 연 버튼으로 포커스 복귀
  • 버튼 순서: 닫기(왼쪽) → 주 행동(오른쪽). 그냥 닫는 보조 버튼은 닫기, 취소는 업로드·결제처럼 진행 중인 작업을 실제로 멈출 때만(Design.md §6 Dialog). 확인 대화상자는 첫 포커스를 닫기에 두고, 위험 행동은 .btn-danger
  • 390px에서 바닥 버튼은 반씩 나눠 꽉 채운다

드로어

  • 데스크톱: 오른쪽 시트, 폭 --drawer-w(400), 높이 100%. 640px 이하: 하단 시트(최대 85%, 위 모서리 --r-lg)
  • 머리(제목 + 닫기) · 스크롤되는 본문 · 바닥(초기화 왼쪽, 결과 보기 오른쪽) 3단. 키보드 규약은 모달과 같다(<dialog> 재사용)
  • 필터·행 상세처럼 지금 화면을 보면서 고르는 일에 쓴다. 저장·삭제 확인은 모달

드롭다운 메뉴

  • 트리거 aria-haspopup="menu" + aria-expanded. 메뉴는 role="menu", 항목은 role="menuitem" tabindex="-1"
  • ↓/↑ 이동(순환) · Home/End · Enter 실행 · Esc 닫고 트리거로 복귀 · Tab·바깥 클릭은 닫기만. 트리거에서 ↓는 첫 항목, ↑는 마지막 항목으로 연다
  • 기본은 트리거 왼쪽 끝에 맞춰 열리고, 화면 오른쪽 끝(표 행의 ⋯ 등)에서는 .menu-end로 오른쪽 맞춤. 항목 높이 --hit-min(40), 표면은 surface + --shadow-pop, z-index: var(--z-dropdown). 위험 항목은 구분선 아래 negative 글자

툴팁

샤프 지수 1.42 연 환산 초과수익 ÷ 변동성. 무위험수익률은 국고채 3년 2.58% 기준 목표 비중을 먼저 정해 주세요
  • hover와 키보드 focus 모두 300ms 뒤에 열린다. blur·mouseleave·Esc로 닫힘. 말풍선 위로 마우스를 옮겨도 유지
  • 트리거에 aria-describedby, 말풍선 role="tooltip". 비활성 버튼에 설명을 달 땐 disabled 대신 aria-disabled(포커스를 받아야 하므로)
  • 표면은 차트 툴팁(.tip)과 같다: surface + border + --r-md + --shadow-pop, --fs-xs. 최대 폭 260. 중요한 정보는 툴팁에만 두지 않는다
